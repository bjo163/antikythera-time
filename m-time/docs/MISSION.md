# Mission

M-Time is a universal temporal interoperability protocol.

North Star:

> Every time-related statement should be able to answer WHAT happened, WHEN, in which scale/frame,
> observed WHERE, computed HOW, under which calendar rule, applicable to which jurisdiction,
> decided by which authority, with what uncertainty, and from what provenance.

Primary real-world proving ground: Ramadan, Syawal and Zulhijjah/Hajj calendar resolution.
