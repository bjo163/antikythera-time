# M-Time Research Charter

## Scientific boundary

M-Time MUST distinguish:
OBSERVED, MEASURED, CALCULATED, MODELED, INFERRED, RECONSTRUCTED, SPECULATIVE, TEXTUAL_REFERENCE.

It MUST NOT:
- invent a new SI second;
- claim one absolute universal simultaneity;
- use scripture as a hidden numerical prior;
- promote an authority decision into an astronomical fact;
- promote a calendar criterion into an observation;
- promote an Antikythera reconstruction into surviving evidence;
- decide which legitimate fiqh/calendar profile is theologically correct.

## Calendar neutrality

The engine evaluates explicit profiles. It does not choose a religious authority.

## Falsification

A failed external reference test is a result. Thresholds may not be widened merely to make CI green.
