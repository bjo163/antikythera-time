# M-Time 0.1 Protocol Draft

Status: RESEARCH DRAFT.

## Principle
M-Time is a universal temporal interoperability protocol, not a replacement for the SI second or UTC.

A temporal resolution MUST keep these layers separable:
1. physical/coordinate time;
2. astronomical state;
3. calendar profile and criterion result;
4. observation evidence;
5. jurisdiction;
6. authority decision;
7. calendar result;
8. uncertainty/provenance.

## Hijri rule
A Hijri astronomical result MUST NOT itself be labelled an official religious/calendar decision.
A criterion result MUST identify profile ID and version.
An authority result MUST cite jurisdiction and source document.

## Revelation
Textual/revelation references MUST be TEXTUAL_REFERENCE / CONCEPTUAL and MUST have zero hidden numerical influence on astronomy/cosmology.

## Antikythera
Antikythera cycles are computational primitives. They MUST NOT be used as evidence for an absolute Big-Bang date.

## Conformance
Implementations SHOULD pass the published golden vectors and MUST preserve semantic separation.
