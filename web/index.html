At the fixed Jakarta oracle epoch, M-Time's airless topocentric Moon solution agrees with JPL Horizons to sub-arcsecond scale. Atmospheric refraction remains an explicit optional model rather than a hidden correction.

Why disagreement matters

The same celestial state can map to different dates because observer, profile, rukyat evidence, jurisdiction or authority differs. ExplainDifference records the causal branch instead of hiding it behind a date string.
