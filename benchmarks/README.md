# U-Time v2 Benchmark Set

This directory freezes **summary results and acceptance contracts**, while source observations remain authoritative at their external providers.

External data are not relabelled as U-Time observations.

Sources include:

- IAU SOFA / ERFA;
- IERS;
- NASA GSFC eclipse data;
- JPL Horizons;
- DESI official public Cobaya chains.

Workflow artifacts retain fuller machine-readable output when large external datasets should not be copied into the repository.

Thresholds cannot be widened solely to make a failed build pass; any threshold change is normative and must include scientific rationale.
