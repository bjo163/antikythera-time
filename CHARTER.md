# M-Time Research Charter

## Mission

Build a universal **temporal interoperability protocol**, not a universal absolute clock.

## Non-goals

M-Time MUST NOT:
- redefine the SI second;
- erase UTC/TAI/IAU/IERS standards;
- select one theology or fiqh profile as scientifically "true";
- equate hisab, rukyat, and authority decisions;
- use Qur'anic/Biblical numerical patterns as physical constants;
- claim Antikythera directly calculates the age of the Universe;
- hide model dependence, uncertainty, unknown values, or reconstruction status.

## Evidence states

OBSERVED / MEASURED / CALCULATED / MODELED / INFERRED / RECONSTRUCTED / SPECULATIVE / TEXTUAL_REFERENCE

## Quality classes

REFERENCE / HIGH_PRECISION / APPROXIMATE / RECONSTRUCTION / CONCEPTUAL

## Flagship acceptance criterion

Given two Hijri outcomes, M-Time SHOULD identify whether the disagreement comes from physical input, ephemeris/source version, observer, criterion, observation, jurisdiction, authority, or unknown information.
