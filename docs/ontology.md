# Evidence / Knowledge Ontology

Machine-readable states in `src/cosmology/ontology.js`:

- OBSERVED
- MEASURED
- CALCULATED
- MODELED
- INFERRED
- RECONSTRUCTED
- SPECULATIVE
- TEXTUAL_REFERENCE

They must not be collapsed into one label.

```text
CREATION
-> MEASURE
-> CELESTIAL MOTION
-> FALAK
-> CYCLE
-> HISAB
-> CHRONOLOGY
-> OBSERVATION
-> MODEL
-> VALIDATION
-> UNCERTAINTY
-> KNOWLEDGE BOUNDARY
```

For numerical cosmology the executable pipeline starts at `OBSERVATION`, not at the theological/textual nodes.
