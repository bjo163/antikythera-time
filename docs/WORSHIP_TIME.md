# M-Time Worship-Time Layer

M-Time treats daily worship timing and Hijri month determination as related but distinct problems.

## Fasting window

For an explicitly selected profile:

validated solar ephemeris
→ observer + UT1/EOP
→ Sun apparent/topocentric altitude
→ profile threshold
→ Fajr event
→ …
→ Sunset event
→ fasting window

The first Indonesian profile records Kementerian Agama's use of a Sun-altitude criterion around -20° for Subuh/Fajr. It is versioned and replaceable. It is not encoded as a universal physical constant or as the only religiously valid position.

The end of the daily fast is represented as a Sunset/Maghrib solar event, independently of the Hijri month-start profile.

## Boundary

Astronomical geometry, profile thresholds, religious/legal interpretation, and published official schedules remain separate provenance layers.
