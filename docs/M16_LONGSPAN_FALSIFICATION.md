# M16 Multi-Century Celestial Falsification

DE440s supports the modern interval surrounding M-Time's current research domain. M16 uses a conservative full-year validation interval:

```text
1850-01-01 through 2149-12-31
3600 monthly epochs
```

Reference comparison uses the same explicit IAU 2006 mean-ecliptic-of-date transform as M6.

The report partitions:

- 1850–1899: pre-training historical partition;
- 1900–1999: M8 fitting interval;
- 2000–2099: validation interval;
- 2100–2149: future extrapolation partition;
- 1850–2149: full supported calibration window.

Both Digital V1 and Digital V2 Experimental are evaluated independently.

The purpose is falsification: if V2 only improves the fit interval and degrades pre-1900/future partitions, it must not become default.

This workflow does not claim validity outside the tested interval.
