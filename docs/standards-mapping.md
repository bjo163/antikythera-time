# Standards and Reference Mapping

| U-Time area | External authority/reference | U-Time role |
|---|---|---|
| SI second | BIPM SI | consume/reference |
| TT/TCG/TDB/TCB definitions | IAU resolutions / SOFA | implement + validate |
| Earth orientation / UT1 | IERS | ingest with provenance |
| high-precision solar-system reference | NASA/JPL Horizons / ephemerides / SPICE ecosystem | benchmark/reference |
| eclipse Besselian elements | NASA GSFC eclipse canon | evaluate/reference |
| cosmology posteriors | Planck / DESI | ingest/infer |
| Antikythera history | peer-reviewed historical/archaeoastronomy literature | evidence-labelled reconstruction |
| U-Time record semantics | U-Time 2.0 | project-defined interchange contract |

U-Time does not supersede the external authorities in the second column.
