# Contributing

Contributions are welcome when they preserve U-Time's scientific boundaries.

## Required for numerical changes

- identify the physical/model quantity;
- identify provenance/reference;
- state validity and uncertainty;
- add/modify tests;
- provide an external comparison when one exists;
- do not tune constants to a desired headline result.

## Reconstruction changes

Historical Antikythera claims must distinguish:

- surviving evidence;
- strongly indicated reconstruction;
- reconstructed model;
- hypothetical feature.

## Cosmology changes

Do not mix posterior parameters from incompatible dataset/model combinations.

## Conformance changes

Changes to `spec/` must update the migration/conformance documentation and pass JavaScript, Python and Rust compatibility gates.
